# Environment for hgb/ (link prediction on AMAZON and the HGB node-classification scripts)
#
# Python: 3.9 (the README's 3.9.18; the prebuilt sparse_tools extension in
#   sparse_tools/sparse_tools/*.pyd links python39.dll + torch 2.x, so 3.9 lets you
#   skip the C++ build). 3.10 / 3.11 also have wheels for every pin below, but then
#   sparse_tools must be rebuilt (`cd sparse_tools && python setup.py develop`, needs
#   MSVC Build Tools) -- only the node-classification / ogbn paths use it.

# GPU: RTX 4070 Super (Ada, sm_89) needs CUDA >= 11.8. Install order on Windows:
#   pip install torch==2.1.2 --index-url https://download.pytorch.org/whl/cu121
#   pip install torch_sparse==0.6.18 -f https://data.pyg.org/whl/torch-2.1.2+cu121.html
#   pip install -r requirements.txt
#
# dgl: the previous pin dgl==2.1.0 has NO Windows wheel (PyPI and data.dgl.ai are
#   Linux/macOS only). 2.2.1 is the only 2.x release with win_amd64 wheels (cp38-cp312)
#   and its release notes list PyTorch 2.1.0/1/2 as supported. The plain PyPI (CPU)
#   build is enough here: dgl is used only for the one-time mean propagation, which
#   runs on the CPU graph (utils.load_dataset / hg_propagate_feat_dgl). dgl 2.2 imports
#   torchdata DataPipes, which torchdata >= 0.8 removed -> pin torchdata 0.7.1
#   (it only requires torch>=2).
